🛡️ Resilience Patterns Dashboard

Test and monitor resilience patterns in action

🔌 Circuit Breaker

Stops request when failure rate is high, preventing cascading failures.

🔁 Retry

Automatically retries failed requests up to configured attempts.

⏱️ Rate Limiter

Restricts request frequency to prevent resource exhaustion.

⏳ Time Limiter

Aborts requests that exceed the configured timeout duration.

🚪 Bulkhead

Isolates threads/resources to limit concurrent calls impact.

💡 About This Dashboard

Click "Test Now" to trigger a single call, or "Stress" to test the pattern under load.

The Rate Limiter and Bulkhead stress tests intentionally exceed the configured limits to demonstrate rejection behavior.
